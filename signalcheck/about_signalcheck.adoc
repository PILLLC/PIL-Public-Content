== Overview

SignalCheck is a lightweight, scenario-driven cyber readiness platform designed to simulate real-world security incidents and evaluate decision-making under pressure.

Built for speed, flexibility, and realism, SignalCheck enables organizations to move beyond static training into interactive, outcome-driven learning.

== Key Value Proposition

* Transform cybersecurity training into active decision-making
* Reinforce critical thinking under realistic conditions
* Provide measurable insight into user behavior and response patterns
* Deliver lightweight, deployable simulations without heavy infrastructure

== How It Works

SignalCheck presents users with structured incident scenarios, each composed of sequential steps requiring decisions that impact the outcome.

Each choice dynamically affects:

* Attacker Advantage
* Operational Impact
* Investigation Clarity
* User Confidence

Scenarios evolve in real time, incorporating injects and branching paths based on user actions.

== Example Scenario Flow

[cols="1,3", grid=none]
|===
|Step 1:
|Initial alert received (e.g., vendor compromise)

|Step 2:
|User selects investigative or dismissive action

|Step 3:
|Scenario branches based on decision

|Step 4:
|Inject introduced (new intelligence or escalation)

|Step 5:
|Outcome and scoring calculated
|===

== Platform Features

* Scenario-based cyber incident simulations
* JSON-driven case architecture for rapid scenario development
* Dynamic scoring engine with multi-dimensional metrics
* Role-based perspectives (Analyst, Manager, Ethical Hacker)
* Inject system for real-time escalation and realism
* Lightweight web-based interface (Flask + JavaScript)
