This document provides comprehensive details for 25 core transactions within CGI Advantage 4. Each transaction includes an overview, prerequisites, dependencies, process steps, validation checks, reporting, and troubleshooting.

=== 1. AP Invoice (Accounts Payable Invoice)

* **Module**: Accounts Payable
* **Purpose**: Used to record vendor invoices for expenses incurred.
* **Usage**: Primarily used by Accounts Payable departments to track vendor invoices.

==== Prerequisites and Dependencies

[cols="3,3", options="header"]
|===
| Table | Description
| Vendor Profile (VEN) | Stores vendor information.
| Budget Control Table | Checks budget availability.
|===

==== Key Fields and Data Elements

[cols="3,3,4", options="header"]
|===
| Field Name | Required/Optional | Description
| Invoice Number | Required | Unique identifier for each invoice.
| Vendor ID | Required | Links the transaction to a vendor profile.
| Account Code | Required | GL account used for the expense.
|===

==== Process for Creating and Processing AP Invoice

. **Navigate to AP Invoice**: Go to `Accounts Payable` > `Invoice`.
. **Enter Header Information**: Include Invoice Number, Date, and Amount.
. **Link to Vendor**: Enter Vendor ID.
. **Enter Line Items**: Specify account codes and amounts.
. **Submit for Approval**: Submit the transaction.
. **Post Transaction**: Finalize and post.

==== Validation and Troubleshooting

* **Budget Errors**: Check the Budget Control Table for availability.
* **Vendor Profile Missing**: Ensure Vendor ID is set up.
