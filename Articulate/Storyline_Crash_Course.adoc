By the end of this 1-day quick start course, participants should have a solid understanding of Articulate Storyline and be able to create interactive eLearning courses with confidence. The hands-on exercises throughout the day will reinforce the concepts learned in each module, and participants will leave with a completed project and the skills to continue exploring and creating in Articulate Storyline.
